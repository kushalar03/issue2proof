# Issue2Proof 2.0.0

Issue2Proof is now an executable repository-memory system for AI-built software.

## Added

- Versioned, evidence-gated Memory Capsules with provenance, assumptions,
  boundaries, hashes, operation IDs and frozen regressions.
- Cross-session lexical and Qwen semantic recall with cached embeddings.
- Nemotron Nano capsule indexing, Super conflict analysis and conditional Ultra
  adjudication.
- Fresh-sandbox memory replay with preserved, violated and uncertain outcomes.
- Public GitHub repository import with fixed-origin bounded downloads.
- Lifetime $25 budget accounting with a hard application stop and per-role usage.
- Official quickstart image-tag resolution to immutable sandbox UUIDs.
- Live browser, sandbox, model, embedding and full conflict-audit evidence.
- MCP recall and audit tools that complete recall → edit → sandbox replay inside
  compatible coding-agent sessions.
- A reproducible 30-trial Nemotron refactor benchmark: plain CI detected 3 of 8
  introduced regressions; capsule replay detected all 8.
- A composite GitHub pull request Memory Gate with free local recall and optional
  authenticated Nebius Sandbox replay.
- Integrity-checked portable capsule bundles plus bulk adoption from verified
  historical Issue2Proof reports.
- A 12-trial recall-routing evaluation across four verified histories, with 12 of
  12 correct top-1 selections for both lexical and changed-path-aware retrieval.
- A responsive light interface with warm paper, sage and clay styling, clearer
  workflow hierarchy and a simplified mobile experience.
- Focused Overview, Workspace, Memory, Integrations and Evidence pages with
  reduced-motion support, scroll reveals, animated evidence diagrams, responsive
  navigation and an interactive MCP walkthrough.
- A fresh Codex-hosted MCP validation artifact, narrated 39-second MCP clip, and
  161-second multi-page submission video with synchronized pointer and captions.

## Retained and strengthened

- Added restricted judge credentials, deployment-authenticated capsule imports,
  credential-aware MCP archiving, redirect-safe HTTPS integrations and shell-safe
  GitHub Action inputs.
- Updated vulnerable TLS, test and packaging dependencies; the locked environment
  now reports no known advisories in `pip-audit`.

- Reproduce-before-repair, frozen tests and withheld independent checks.
- Wheel-only dependency preparation and offline unprivileged execution.
- Durable jobs, leases, cancellation, explicit resume, retention and deletion.
- Authenticated private deployment and downloadable evidence bundles.

## Validation

134 tests pass with Ruff and JavaScript syntax checks. The full live Werkzeug audit
used three sandbox calls and two model calls, reached `memory_conflict`, and stayed
within its $0.75 allowance. Historical cases are demonstrations rather than a
held-out benchmark.

The public application is hosted on Vercel. A persistent authenticated deployment
is supported through the Render Blueprint for fresh repository investigations.
