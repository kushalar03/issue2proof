# Issue2Proof 2.0 status

The submission implementation is complete as an executable repository-memory
product rather than a single-session repair assistant.

Implemented and validated:

- Versioned Memory Capsules backed only by checks-passed execution evidence.
- Free lexical recall and batched Qwen semantic recall with cached vectors.
- Nemotron Nano capsule indexing, Nemotron Super engineering analysis and bounded
  Nemotron Ultra escalation.
- Replay of frozen historical regressions on future repository revisions, with
  preserved/violated/uncertain classification and dirty-baseline visibility.
- GitHub root repository import plus the bounded ZIP path.
- Lifetime $25 ledger with a protected $5 reserve and per-role accounting.
- Activated Nebius Sandbox quickstart image resolution, wheel-only pytest
  preparation, network-disabled disposable checks and live evidence.
- Authenticated browser workflow, durable background jobs, cancellation, recovery,
  retention, exports and private deployment configuration.
- Responsive light presentation validated at desktop and mobile widths.
- 126 passing tests, Ruff and JavaScript syntax validation.

Remaining publication work is external to the codebase: push a public repository,
deploy to an operator-provided HTTPS host, upload the under-three-minute demo and
paste those URLs into Devpost. No server, domain or publication account is
configured in this workspace.
