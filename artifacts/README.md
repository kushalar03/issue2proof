# Validation evidence

This directory contains the compact evidence set needed to assess the project:

- real repairs for Werkzeug, Requests, uploaded source and dependency handling;
- a rejected candidate showing that a plausible patch can fail independent checks;
- live Nebius Sandbox activation and model-catalog validation;
- Memory Capsule indexing, semantic retrieval and regression replay;
- MCP recall-to-audit validation;
- the 30-trial regression-memory impact benchmark; and
- the final release validation summary.

Transient browser traces, duplicate smoke-test outputs, cancelled-job snapshots and
intermediate recording assets are intentionally excluded from the public repository.
The complete behavior remains reproducible through the test suite and scripts.
