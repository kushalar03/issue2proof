# Publish the release

1. Review README.md, the Devpost draft, historical fixture licenses and live evidence.
2. Source is published at https://github.com/kushalar03/issue2proof without .env, databases, API keys or local caches.
3. Upload `submission/final-demo.mp4` (161.36 seconds, chapter-synchronized voice narration, captions in a dedicated band, a guided pointer, and the real Codex MCP recall → audit workflow) and use its real URL in the submission.
4. The public interactive demo is available at https://issue2proof-demo.vercel.app.
5. Deploy the authenticated judge instance from `render.yaml` and follow
   `docs/RENDER_JUDGE_DEPLOYMENT.md`. Share its temporary access token only through
   private judging instructions. Railway remains an alternative after sign-ups
   reopen.
6. Enter the actual repository, Vercel tour, live Render application, and video
   URLs in the current required hackathon fields, then submit through your account.

The public demo uses the production interface with a recorded-evidence adapter. Its
controls work without exposing an application token or running paid jobs. Fresh
model and sandbox execution remains available through the authenticated deployment
described in docs/DEPLOYMENT.md.

The currently published deadline is October 30, 2026 at 10:00 AM Pacific
(10:30 PM India Standard Time). Recheck Devpost immediately before publication.
